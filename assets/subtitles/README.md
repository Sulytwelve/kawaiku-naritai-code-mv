# 字幕占位与替换

此目录只随仓库提供说明，不分发歌词、译文或字幕文件。本地工作副本可自行放入 SRT，字幕文件保持 Git 忽略。歌词以外部 SRT 提供，不默认烧入画面；入口只在使用 `--srt` 时读取对应字幕源。作品为 HoneyWorks《可愛くなりたい》，作者与官方来源见 [素材出处](../../docs/ASSET_ATTRIBUTION.md#歌曲与原-mv)；来源链接用于识别作品，不代表取得复制、改编、翻译、发布或再分发许可。

## 文件名与内容契约

入口只接受两种 `--srt` 值，并读取固定文件名；其他值会被拒绝，不会回退成日文，也不会按传入字符串另造语言后缀。

| 参数 | 字幕源 | 内容 |
| --- | --- | --- |
| `--srt ja` | `assets/subtitles/KAWAIKU NARITAI.ja.srt` | 日文字幕。 |
| `--srt bilingual` | `assets/subtitles/KAWAIKU NARITAI.bilingual.srt` | 预制双语字幕；每个 cue 内是多行文本。 |

两个文件都由使用者准备，渲染器不生成、不补全。`ja` 与 `bilingual` 是两份独立的源：`bilingual` 的译文不是由 `ja` 自动翻译产生，多行也不是渲染器合并或拆分的结果；每个 cue 写什么、有几行，完全取决于源文件。当前没有 `zh` 或 `zh-CN` 参数；需要单独中文时，应另备已校时且有使用依据的字幕，不能只改文件名冒充受支持的输入。

## Agent 准备字幕

1. **合法取得或自行制作。** 通过权利人允许的渠道取得歌词与译文，或自行编写占位文本；保留作者、来源和使用条件记录。歌词、译文及其翻译不适用本工程代码的 BSD 许可，不要从歌词网站、视频字幕或现成翻译直接抓取后提交，也不要把歌词或译文写进 README、提交信息或 issue。素材权利范围见 [许可范围](../../LICENSING.md)。
2. **保存为 UTF-8 标准 SRT。** 每个 cue 依次为序号、时间行、文本块，块间用空行分隔；时间行写成 `HH:MM:SS,mmm --> HH:MM:SS,mmm`，毫秒用逗号。多行文本放在同一 cue 的文本块内，空行会被当作 cue 分隔。文件用 UTF-8 保存，建议不带 BOM。程序只读取时刻和文本，不校验序号连续性，也不清理或转换样式；时间行格式不合法时该条可能被跳过，结构由源文件自己保证。
3. **按歌曲时钟校时。** 字幕时间从整首歌的 0 秒起算，是歌曲时钟，不是 source PTS，也不是输出视频自己的 0 秒。现有镜头与字幕按 Sana 版校时，也可使用成海聖奈（CV：雨宮天）版；更换歌曲、版本、速度、前奏长度或音轨起点后，必须重新核对首尾 cue、与歌声对齐、成片长度和音乐署名，不能只改文件名。音轨准备与版本差异见 [音轨准备](../audio/README.md)。
4. **局部输出会平移并裁剪。** `--output-range 44 56` 按歌曲时间减去 44 秒；`--range 44 56` 按 source PTS 减去 `startPTS + --audio-offset`，默认 `0.064` 秒，即 44.064 秒。平移后只保留与输出时长相交的 cue：跨起点的夹到 0，跨终点的裁到输出结尾，完全在窗口外或裁剪后长度为 0 的删除，再从 1 连续编号。整片导出不额外加 64 ms（该偏移属于画面 source PTS 映射，不是字幕补偿）。`--no-audio` 只关闭声音，不把字幕时间基准归零，仍按所选片段对应的歌曲时钟平移。完整参数和输出检查见 [复现指南](../../docs/REPRODUCING.md)。
5. **保持 Git 忽略。** [`.gitignore`](../../.gitignore) 用 `assets/subtitles/*` 忽略本目录除说明以外的内容，再用 `!assets/subtitles/README.md` 重新包含本说明；全局 `*.srt` 仍然排除所有字幕文件，包括子目录中的文件。不要用 `git add -f` 绕过排除规则。需要确认某个文件时运行 `git check-ignore -v "assets/subtitles/KAWAIKU NARITAI.ja.srt"`；本 README 不在忽略范围内，可用 `git status --short --untracked-files=all assets/subtitles/` 核对。

## 占位示例

以下内容仅用于确认结构、多行文本和局部裁剪，是自拟的占位说明，不是歌词，也不是任何现有译文。实际使用时替换为自己的字幕源。

```srt
1
00:00:05,000 --> 00:00:08,000
（自拟占位）这一行只用于检查字幕时间窗口。

2
00:00:09,000 --> 00:00:11,500
（自拟占位）第一行占位文字
（自拟占位）第二行占位文字
```

第二个 cue 的多行文本演示双语文件的写法；日文文件通常每个 cue 一行。两个 cue 都是虚构的说明文字。

字幕源、音轨与成片必须使用同一版本、同一速度的歌曲时钟；任一方更换后都要重新校时并核对署名。
