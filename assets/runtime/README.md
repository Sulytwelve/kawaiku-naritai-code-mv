# 运行输入与公开范围

此目录包含场景消费的数据与图像输入，不是可整体删除的渲染输出目录。是否随仓库分发取决于具体文件，不能因为位于 `runtime/` 就整体提交。

| 内容 | 用途 | 分发边界 |
| --- | --- | --- |
| JSON 登记、轨迹、几何与序列清单 | 描述图层位置、相机、表情配准、转场轮廓及 SNS 帧序列；也保留部分测量参考。部分在模块导入时读取，删除会影响覆盖检查或渲染。 | 现有 JSON 随源码提供；其中原作来源说明应保留。数据中的媒体路径不表示相应文件已公开或获得许可。 |
| `expression-patches/`、`fashion/`、`opening-assets/` 中逐文件允许的 PNG | 人物表情补层、服装纸片与眨眼补层。 | 只有 [素材清单](../asset-licenses.json) 中 `commitAllowed: true` 且列入 `.gitignore` 例外的图片随仓库分发，沿用各自许可。 |
| 其他 PNG、WebP 及 SNS 烘焙序列 | 场景合成图、原片派生层、屏幕纹理和投影帧等本地输入。 | 默认排除；不因被代码引用就可以公开。需按素材清单合法准备或重新制作。 |

主要消费者位于 `production/mv/` 的 `*-scenes.mjs`、`social-web-film.mjs` 等模块。先追踪活动代码和清单，再决定修改某个输入；`timeline.json` 与 `phone-timeline.json` 只记录帧名和顺序，不包含所指向的全部位图，也不能自动重新生成它们。

替换图片时要同步配准坐标、尺寸、alpha、序列与许可记录。公开克隆能通过覆盖检查，不代表整片图像已经齐全。详见 [架构说明](../../docs/ARCHITECTURE.md)、[复现指南](../../docs/REPRODUCING.md) 与 [许可范围](../../LICENSING.md)。
