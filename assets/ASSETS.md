# Assets

Project artwork lives in [`visuals/`](visuals/); the renderer's layered images and timing data live in [`runtime/`](runtime/). Adapted source imagery is a separately supplied local input under `third-party-derived/`, and standalone prop metadata is in [`props/`](props/).

Music and font files are not distributed. Their directories contain [audio preparation instructions](audio/README.md) and [font replacement instructions](fonts/README.md); subtitles are separately supplied in `subtitles/`. See the [runtime distribution boundary](runtime/README.md), [asset attribution](../docs/ASSET_ATTRIBUTION.md), the [file-level license inventory](asset-licenses.json), and [project licensing](../LICENSING.md) for source and use terms. The directory names do not grant rights.
