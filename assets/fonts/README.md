# 字体占位与替换

仓库不分发字体二进制文件。请 Agent 根据需要显示的中文、日文和拉丁文字，自行查找具有明确许可、允许目标用途的字体，并保留其作者、来源和许可记录。取得本地使用权不应被当作可以把字体文件提交到仓库的依据。

## Agent 配置字体

在运行渲染前，通过以下环境变量指定自己准备的字体文件，值为文件的绝对路径：

| 变量 | 渲染器注册族名 | 用途与现有默认值 |
| --- | --- | --- |
| `MV_FONT_PATH` | `MV Gothic` | 主要文字；Windows 默认尝试系统 `msyh.ttc`。 |
| `MV_TITLE_FONT_PATH` | `TitleRound` | 标题文字；Windows 默认尝试系统 `YuGothM.ttc`。 |
| `MV_SOURCE_FONT_PATH` | `SourceDisplay` | 中文标题；源码保留旧输入名 `assets/fonts/汉仪跳跳体简5.0.ttf`，仓库不提供该文件，也不要求使用这款字体。应通过此变量指定合法替代字体。 |

例如，在 PowerShell 中将自己的字体路径赋给 `$env:MV_SOURCE_FONT_PATH`，再执行渲染。完整环境变量示例见 [复现指南](../../docs/REPRODUCING.md#运行环境)。非 Windows 平台应显式配置所需字体。

缺少字体时存在回退行为，命令成功不能证明字形正确。替换后应检查中文标题、日文字幕或署名的缺字、字重、换行、对齐与边界，先审看局部再渲染整片。某些字已经存在于位图输入中，设置这些变量不会更换图片里的文字。

此目录默认忽略说明以外的文件。不要复制系统字体、商业字体或来源不明的字体进入公开提交，也不要用 `git add -f` 绕过排除规则；运行时和系统字体保留各自许可，见 [许可范围](../../LICENSING.md)。
