# 字体与音轨输入

返回 [任务索引](README.md)。保持媒体排除规则，不随此任务下载或提交音乐及字体。

> 实现状态：已完成并验证，见 [任务索引的状态表](README.md#实现状态2026-10-22)。本页保留立项时的基线描述与验收条件；当前接口、命令与限制以代码和 [复现指南](../REPRODUCING.md) 为准。

## I01 字体注册诊断

**优先级：高。**

### 已确认的现状

[`scene.mjs`](../../production/mv/scene.mjs) 中主字体不存在时直接跳过；`SourceDisplay` 注册位于空 `catch` 中。[`title-scenes.mjs`](../../production/mv/title-scenes.mjs) 的 `TitleRound` 也有相同的静默行为。当前安装的 Canvas 类型定义中 `registerFromPath()` 返回 `FontKey | null`，因此只捕获异常不足以覆盖注册失败。

公开仓库没有 `assets/fonts/汉仪跳跳体简5.0.ttf`；未通过环境变量指定替代字体的新克隆可能无声回退。字体成功注册也不等于包含所需全部字形，两者应分别描述。

### 实现要求

- [ ] 汇总三个槽位：`MV Gothic` / `MV_FONT_PATH`、`TitleRound` / `MV_TITLE_FONT_PATH`、`SourceDisplay` / `MV_SOURCE_FONT_PATH`。
- [ ] 区分未配置、文件缺失、注册失败（返回空值或抛错）及注册成功，记录尝试的路径和配置来源，避免把 `existsSync` 当作注册成功。
- [ ] 对不可用槽位输出一次性明确 WARNING，包含槽位、原因和替代配置方法；不要每帧刷屏，也不要继续用空 `catch` 吞掉所有诊断。
- [ ] 在 dry-run plan 和实际旁车中输出结构化 `fonts` 状态。可使用 `status`、`path`、`source`、`reason` 等字段；不要求某种固定内部结构，但应便于 Agent 判断。
- [ ] 缺字体不能使纯 coverage 或参数规划无法运行；允许回退时应清楚标记“未注册/使用系统回退”，不能伪报指定字体成功。是否增加严格字体模式可另行选择，不是本任务硬要求。
- [ ] 保留对系统字体和合法替代字体的支持；不把商业字体或一个特定字体品牌变成安装依赖。
- [ ] 注册和路径诊断不得被误写成逐字字形覆盖检查；缺字及排版仍需适用的视觉验收。本地报告含绝对路径时继续保持忽略，不提交这些报告。

### 验收

- 分别模拟有效字体、缺失文件、存在但无法解码的文件、未设置变量的平台默认路径；状态与警告一致，不出现伪成功。
- 空返回值与异常都被处理；三个槽位的报告互不覆盖。
- coverage 和 dry-run 在字体缺失时仍可完成适用检查，并报告实际状态；有效替代字体的局部画面需要检查标题、缺字及布局。

## I02 本地音轨覆盖

**优先级：中。**

### 已确认的现状

[`render-film.mjs`](../../production/mv/render-film.mjs) 仅从跟踪的 [`ASSET_INDEX.json`](../../assets/ASSET_INDEX.json) 取 `audio`。字体、FFmpeg 可通过环境变量配置，而选择本地音轨需要改动清单。现有 JSON 路径逻辑也不应直接照搬为绝对路径覆盖的实现。

### 实现要求

- [ ] 增加 `MV_AUDIO_PATH`，优先于 `ASSET_INDEX.audio`，未设置时保持原清单默认。无需在本轮扩展一套通用配置系统。
- [ ] 明确路径规则：建议绝对路径直接使用，相对路径相对仓库根解析；支持空格、中文及 Windows / POSIX 路径，不能把绝对路径再次拼接进根目录。
- [ ] 空字符串如何回退应固定并记录；非空但错误的显式路径应报告错误，不静默改用默认音乐。正常编码时检查输入，coverage / dry-run / `--no-audio` 保持不依赖音轨实际存在。
- [ ] 日志、plan、旁车标明输入来源（环境变量或清单）、解析结果及是否启用音轨。无声输出不得声称使用了歌曲。
- [ ] 更新音轨 README 和复现文档：新复刻者默认寻找雨宮天版，也可用 Sana；已有校时和默认声明仍对应 Sana。覆盖路径不自动完成另一版本的时序重配。
- [ ] 环境变量不能改写被跟踪的清单；不提交 `.env`、本地文件或报告。更换版本后仍需校对时间轴、整片长度、字幕和音乐署名。

### 验收

- 覆盖优先级、未设置、空值、错误路径、含空格/中文路径均有针对性检查；不要声称在未运行的平台上验证过路径行为。
- 设置覆盖并进行 dry-run / 短片输出后，Git 中的 `assets/ASSET_INDEX.json` 没有变化。
- 使用自产短音轨或有使用依据的现有本地输入，确认 FFmpeg 实际收到覆盖路径。缺少默认曲目时，coverage、dry-run 和无声模式依旧可用。
