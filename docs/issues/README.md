## 开始前

1. 阅读 [Agent 指南](../../AGENTS.md)、[架构](../ARCHITECTURE.md)、[复现指南](../REPRODUCING.md) 和 [许可范围](../../LICENSING.md)。
2. 重点入口为 `production/mv/render-film.mjs`；字体分别在 `scene.mjs` 与 `title-scenes.mjs` 注册，时间映射在 `film-clock.mjs`。
3. 沿用现有动画、素材、配准和时间轴。不要为这些接口改进重写合成器、批量生成素材、下载商业字体或补入原曲。
4. 保留 `ready`、coverage、`--preview-release` 和输出路径保护机制；不要用改变门控状态的方式让验证通过。
5. 各页中的“建议接口”是立项时的契约记录，不应直接当成当前可执行命令；当前行为以代码和 [复现指南](../REPRODUCING.md) 为准。

## 共用验收边界

- 先做参数和纯逻辑检查，再用短片验证实际编码；无需为这些改动反复渲染完整 4K MV。
- 对编码器、位深、非法参数、字体状态和字幕裁剪增加有针对性的检查。字幕用原创合成文本作夹具，不提交歌词。
- 使用现有 `npm run coverage` 确认路由覆盖不变。覆盖检查通过不能被表述为完整画面、字体或音轨已经验收。
- 编码环境缺少某个编码器时，说明实际缺少的能力；只有实际编码并用 ffprobe 核对后，才记录该组合已验证。未执行的平台与硬件不写成已通过。
- 更新根 README、`docs/REPRODUCING.md`、相关资源 README 和 Agent 指南中受影响的现有行为描述，避免新旧说明冲突。不要提前把本任务单中的设想写成已实现功能。
- 音乐、字体、字幕、未批准图片、编码输出和本地绝对路径不进入公开提交；逐文件图片白名单与第三方许可不扩大。
- 完成时报告：实现的 ID、实际验证的命令与结果、跳过项及其原因、仍缺少的输入。未经另行安排，不进行远程推送或发布。

## 不应作为缺陷处理的事项

- 旧字体文件名本身不是本轮重命名任务；真正的问题是注册状态不可见。可以保留兼容回退，不应要求新克隆具备该商业字体。
- `--range` 的 source PTS 与 `--output-range` 的歌曲时间是已有接口契约；两者取相同数字并不代表相同片段。
- 图片缓存、二分查找和语法错误不在本清单立项。本次没有独立复核它们的整体正确性，不将外部分析中“已全部通过”的说法作为本次测试结果。
- 字幕目录默认排除是现有分发边界，S04 仅公开说明文件。

本目录作为阶段任务资料保留；删除应等待维护者另行指令。完成后的长期接口说明应已进入对应技术文档，使删除任务单不影响后续接手。
